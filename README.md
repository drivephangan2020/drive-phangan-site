# Drive Phangan — дизайн-макет сайта (статичная версия)

Готовый HTML/CSS-макет нового дизайна сайта. Это **макет для переноса**, а не рабочий сайт:
данные (скутеры, авто, цены) зашиты в страницы как снимок с превью-сайта, бронирования и базы нет.

## Как открыть

Распакуйте папку и откройте `index.html` в браузере. Для шрифтов нужен интернет (Google Fonts: Anton, Manrope).
Лучше смотреть через локальный сервер, например:

```
npx serve .
```

## Страницы

| Файл | Страница | Маршрут на сайте |
|---|---|---|
| `index.html` | Главная | `/{en,ru,uk}` |
| `scooters.html` | Скутеры (каталог, фильтры, расчёт по датам) | `/{lang}/scooters` |

Каждая страница — один самодостаточный файл: CSS и JS внутри, картинки в `img/`.

## Общие элементы (одинаковые на всех страницах)

- **Шапка** `.hdr`: прозрачная с размытием, фото страницы заходит под неё (`margin-top:-84px` у первого блока).
- **Языки**: выпадающее меню EN / RU / UA (код языка `uk`). В макете переключение на JS (`setLang`, словарь `T`, атрибуты `data-i18n`), выбор хранится в `localStorage`. На сайте — отдельные URL `/en`, `/ru`, `/uk`.
- **Меню на телефоне** `.mnav`: стеклянная панель, вынесена из шапки (иначе в Chrome не работает размытие).
- **Низ страницы** `.ftr`: блок «Готовы к поездке?» + стеклянная панель с меню и адресом. Меню и адрес всегда в одну строку (функция `fitFtr` уменьшает шрифт на телефоне).
- **Цвета и шрифты**: токены `--tp-*` в начале `<style>` (фон `#0A0E18`, акцент `#FF7A1A`, Anton + Manrope).
- **Кнопки**: `.btn--glass` (прозрачная, оранжевая при наведении), `.btn--primary` (оранжевая).

## Картинки: десктоп + отдельные для телефона

Через `<picture>` с `media="(max-width:760px)"`:

| Где | Десктоп | Телефон |
|---|---|---|
| Главная, верх | `hero-island.webp` | `hero-island-mobile.webp` |
| Главная, низ | `footer-viewpoint.webp` | `footer-viewpoint-mobile.webp` |
| Условия, верх | `terms-hero-robot.webp` (фикс. масштаб 1873×724) | `terms-hero-mobile.webp` |
| Условия / контакты / гид / скутеры / авто, низ | `footer-road.webp` | `footer-road-mobile.webp` |

Рекомендуемые размеры: широкие 2560×1000 (минимум 1920×750), мобильные 1080×1350–1500, WebP до ~300–500 КБ.

## Главная: картинка с машинами и скутерами

`rides-circle.webp` + маски `mask-cars.webp`, `mask-scooters.webp` (PNG-силуэты того же размера 1300×1300).
Подсветка: SVG-фильтр `#rp-glow` строит обводку по маске. На мышке — наведение, на телефоне — касание (в т.ч. при прокрутке), второе касание открывает страницу.
Зоны клика — полигоны `.rp-hot`.

## Что заменить при переносе на сайт

- **Каталоги скутеров и авто** — сейчас 27 скутеров и 5 авто зашиты в HTML. Карточки нужно рендерить из базы (те же классы `.sc-card` / `.cr-card`, data-атрибуты для фильтров: `data-cat`, `data-brand`, `data-model`, `data-cc`, `data-year`, `data-colour`, `data-price`).
- **Фото скутеров** — у всех стоит временная `scooter-placeholder.webp` (как на превью-сайте).
- **Фильтр «только свободные на мои даты»** и реальная цена по датам — нужен бэкенд. Сейчас итог = цена за день × дни (без сезонов и скидок).
- **Ссылки «Подробнее»** ведут на страницы машин на текущем превью-сайте (`drive-preview.../vehicles/...`) — заменить на маршруты сайта.
- **Отзывы Google** на главной — 6 карточек-заглушек с пометкой «Пример». Нужны реальные отзывы и точная ссылка на страницу в Google Maps.
- **Кнопка «Посмотреть договор аренды»** на странице условий никуда не ведёт.
- **Плашка «Claude preview»** вверху каждой страницы — удалить (`.note`).
- **Гид**: фото мест с Wikimedia Commons — блок «Авторы фотографий» обязателен по лицензиям CC BY / CC BY-SA.
- **Контакты**: в коде есть TODO из исходной страницы (ответы текущим арендаторам вне рабочего времени, ориентир рядом с офисом). Добавить в `<head>` JSON-LD `AutoRental` (адрес, телефон, часы работы) — пример в старом файле `docs/site-contacts/drive-phangan-contacts.html`.
